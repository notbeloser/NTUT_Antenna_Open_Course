# 單元 17｜指向性

把場型換成能量集中程度

原始影片：[陳晏笙老師「天線」單元 17](https://www.youtube.com/watch?v=IBood8ipth4)

影片長度：約 71 分鐘　建議閱讀：約 25 分鐘

前置單元：16。需理解輻射強度、正規化功率與切面。

> **核心觀念：** 指向性是在「相同總輻射功率」下，某方向的輻射強度相對於各向同性參考的比值。它描述集中程度，沒有將匹配與耗損算進去。

## 本單元的五個目標

1.  由整個球面的功率積分求峰值指向性。

2.  重算電短偶極與影片半球例題。

3.  把離散角度資料轉成可用的數值積分。

4.  區分峰值指向性與隨方向變化的指向性場型。

5.  用波束立體角、主瓣效率與波束寬度評估集中程度。

## 先分清三個量

| 量                 | 定義                        | 用途                    |
|:-------------------|:----------------------------|:------------------------|
| $`P_n(\theta,\phi)`$ | $`U/U_{\max}`$                | 峰值為 1 的相對功率形狀 |
| $`D_{\max}`$         | $`4\pi U_{\max}/P_{\rm rad}`$ | 最大方向的集中程度      |
| $`D(\theta,\phi)`$   | $`D_{\max}P_n`$               | 每個方向的集中程度      |

最大值為 0 dB 的正規化場型，並不是最大指向性只有 0 dBi。還要知道整個球面的功率分配，才能算出 $`D_{\max}`$。

## 閱讀地圖

第 2 頁：定義與球面積分；第 3 頁：電短與半波偶極；第 4 頁：數值積分；第 5 頁：影片半球算例；第 6 頁：波束立體角；第 7 頁：寬度近似；第 8 頁：波束效率；第 9 頁：自測。 依影片板書與投影片重寫；積分與單位補上完整步驟，補充例題另標。

## 1．指向性從整個球面的平均開始

影片對照：[約 08:00](https://www.youtube.com/watch?v=IBood8ipth4&t=480s)－[22:00](https://www.youtube.com/watch?v=IBood8ipth4&t=1320s)

某方向的輻射強度為 $`U(\theta,\phi)`$，單位 W/sr。球面微小面積 $`dA=r^2\sin\theta\,d\theta\,d\phi`$，對應立體角：

```math
d\Omega=\sin\theta\,d\theta\,d\phi,\qquad
\oint d\Omega=4\pi\ {\rm sr}.
```

總輻射功率是各方向功率的和：

```math
P_{\rm rad}=\int_0^{2\pi}\int_0^\pi
U(\theta,\phi)\sin\theta\,d\theta\,d\phi.
```

此積分要用線性功率，不能把 dB 數字直接相加。

### 各向同性參考為什麼出現 $`4\pi`$？

將相同 $`P_{\rm rad}`$ 均勻分到全空間，各向同性參考的每方向輻射強度為 $`U_{\rm iso}=P_{\rm rad}/(4\pi)`$。因此

```math
\boxed{D(\theta,\phi)=\frac{U(\theta,\phi)}{U_{\rm iso}}
=\frac{4\pi U(\theta,\phi)}{P_{\rm rad}}.}
```

峰值指向性：

```math
\boxed{D_{\max}=
\frac{4\pi}{\displaystyle\int_0^{2\pi}\int_0^\pi
P_n(\theta,\phi)\sin\theta\,d\theta\,d\phi}.}
```

$`P_n=U/U_{\max}`$，因此 $`U_{\max}`$ 在分子、分母相消。只知道正規化形狀，仍可算指向性，不必先知道絕對發射功率。

### 線性比值與 dBi

```math
D_{\rm dBi}=10\log_{10}D.
```

各向同性 $`D=1`$，為 0 dBi。某方向 $`D<1`$ 可有負 dBi；但整個球面的平均 $`D`$ 必為 1，所以 $`D_{\max}\ge1`$。 **補充解說／重算例題：**增加發射功率但場型形狀不變，$`U`$ 與 $`P_{\rm rad}`$ 同倍增加，指向性不變。

> **核心觀念：** 指向性分母是總輻射功率，不是源的供應功率，也不是天線端口接受功率。

## 2．影片的兩個偶極：外形相似，指向性不同

影片對照：[約 22:00](https://www.youtube.com/watch?v=IBood8ipth4&t=1320s)－[24:00](https://www.youtube.com/watch?v=IBood8ipth4&t=1440s)

影片用電短偶極與半波偶極，示範由解析功率場型求峰值指向性。兩者都沿 $`z`$ 軸，方位角 $`\phi`$ 全向，功率只隨 $`\theta`$ 改變。

### 電短偶極：$`P_n=\sin^2\theta`$

```math
\Omega_A=2\pi\int_0^\pi\sin^2\theta\sin\theta\,d\theta.
```

令 $`u=\cos\theta`$，$`du=-\sin\theta\,d\theta`$：

```math
\int_0^\pi\sin^3\theta\,d\theta
=\int_{-1}^1(1-u^2)\,du=\frac43.
```

因此

```math
\boxed{D_{\max}=\frac{4\pi}{2\pi(4/3)}=1.5
\quad\Rightarrow\quad1.761\ {\rm dBi}.}
```

水平面各方位相同，仍有 1.5 的峰值指向性：因為能量沒有均勻分到所有仰角。

### 半波偶極：使用它自己的功率式

```math
P_n(\theta)=
\left[\frac{\cos[(\pi/2)\cos\theta]}{\sin\theta}\right]^2.
```

影片給出的球面積分結果約

```math
\Omega_A\approx7.66\ {\rm sr},\qquad
\boxed{D_{\max}\approx1.64\quad\Rightarrow\quad2.15\ {\rm dBi}.}
```

它的主面外形與電短偶極很接近，但主瓣略集中。兩者的功率曲線和 $`\Omega_A`$ 不完全相同，不能因為都像八字就使用相同指向性。

### 只知道一張切面圖，何時足夠？

本例因已知繞 $`z`$ 軸對稱，可將 $`\phi`$ 積分直接變成 $`2\pi`$，一張完整的 $`\theta`$ 切面已足夠。一般不對稱天線仍需要 $`P_n(\theta,\phi)`$ 的整個三維資料。 **補充解說／重算例題：**上式是理想天線模型的指向性。若加入導體耗損、失配、饋線損耗，實際增益或實現增益可能較低；下一單元會處理。

> **核心觀念：** 全向切面與各向同性全空間不同。場型相似的天線，也可能有不同球面功率積分。

## 3．離散量測資料：積分時不能漏掉 $`\sin\theta`$

影片對照：[約 24:00](https://www.youtube.com/watch?v=IBood8ipth4&t=1440s)－[30:00](https://www.youtube.com/watch?v=IBood8ipth4&t=1800s)

影片以角度表格求分母，並給出一個軸對稱場型的近似結果：HPBW 約 22°，$`D_{\max}\approx18`$，約 12.6 dBi。計算依賴整條功率曲線，包含旁瓣，而不是只看 22°。

### 若 $`\phi`$ 方向全向

均勻 $`\theta`$ 網格可近似：

```math
\Omega_A\approx
2\pi\sum_m P_n(\theta_m)\sin\theta_m\,\Delta\theta,
\qquad D_{\max}\approx\frac{4\pi}{\Omega_A}.
```

影片用 36 段將 $`0`$ 至 $`\pi`$ 分割；步長 $`\Delta\theta=\pi/36`$，為 5°。數值積分步長要用弧度。 球面靠近兩極的小區域，面積比赤道的同角度區域小，所以要乘 $`\sin\theta`$；不能把每列資料當成相同球面面積。

### 一般的三維角度網格

```math
\Omega_A\approx\sum_i\sum_j
P_n(\theta_i,\phi_j)\sin\theta_i\,
\Delta\theta\,\Delta\phi.
```

影片的示範表格亦包含不同方位與仰角。資料處理時：

1.  先合成總功率，或清楚指定僅分析某個極化。

2.  若輸入為相對功率 dB，先轉 $`P_n=10^{P_{\rm dB}/10}`$。

3.  若輸入為幅值，先平方，再按全球最大值正規化。

4.  把角度轉成弧度，乘球面權重；$`\phi=0`$ 與 $`360^\circ`$ 不可重複計一圈。

5.  加密角度網格，確認峰值與積分結果是否穩定。

### 極區用有限面積權重更穩妥

**補充解說／重算例題：**角度格子的精確立體角是

```math
\Delta\Omega_{ij}=
(\cos\theta_{i,\rm low}-\cos\theta_{i,\rm high})\,\Delta\phi_j.
```

用 $`P_n\,\Delta\Omega`$ 加總，可避免粗網格在極區的面積近似偏差。峰值若落在取樣點之間，仍需要更密取樣。

### 影片結果的數值檢查

$`D_{\max}=18`$ 對應 $`\Omega_A=4\pi/18\approx0.6981`$ sr，$`10\log_{10}18=12.553`$ dBi，投影片四捨五入為 12.6 dBi。 另一張離散場型例得到 $`\Omega_A\approx2.83`$ sr，故 $`D_{\max}\approx4.44=6.47`$ dBi。共同乘上一個與角度無關的校正比例，不改變正規化場型與指向性；角度相關的量測誤差仍會改變積分。

> **核心觀念：** 積分線性功率、乘上球面面積權重、避免重複端點。兩張主切面通常不能取代整個三維場型。

## 4．影片半球算例：峰值與方向函數一起求

影片對照：[約 30:00](https://www.youtube.com/watch?v=IBood8ipth4&t=1800s)－[34:00](https://www.youtube.com/watch?v=IBood8ipth4&t=2040s)

影片給出軸對稱輻射強度

```math
U(\theta)=U_{\max}\cos^2\theta,\qquad
0\le\theta\le\frac\pi2.
```

其餘下半球取零；這個範圍是題目的必要條件。如果把同一公式延伸至整個球面，答案會改變。

### 方法一：先算總輻射功率

```math
P_{\rm rad}=2\pi U_{\max}
\int_0^{\pi/2}\cos^2\theta\sin\theta\,d\theta.
```

令 $`u=\cos\theta`$，積分由 $`u=1`$ 至 0：

```math
\int_0^{\pi/2}\cos^2\theta\sin\theta\,d\theta
=\int_0^1u^2du=\frac13.
```

```math
P_{\rm rad}=\frac{2\pi}{3}U_{\max},\qquad
D(\theta)=\frac{4\pi U_{\max}\cos^2\theta}
{(2\pi/3)U_{\max}}=6\cos^2\theta.
```

所以

```math
\boxed{D_{\max}=6=7.782\ {\rm dBi}}
```

最大方向為 $`\theta=0`$。在下半球 $`D=0`$。

### 方法二：先求峰值，再乘正規化場型

```math
\Omega_A=\frac{2\pi}{3},\qquad
D_{\max}=\frac{4\pi}{2\pi/3}=6,
```

```math
D(\theta,\phi)=D_{\max}P_n(\theta,\phi)
=6\cos^2\theta.
```

兩種方法等價；第二種便於將正規化量測場型加上絕對指向性尺度。

### 方向上的 dBi 也可用相加

線性表示是相乘；對非零場，dB 表示變成

```math
D_{\rm dBi}(\theta,\phi)
=D_{\max,\rm dBi}+P_{n,\rm dB}(\theta,\phi).
```

例如 $`\theta=60^\circ`$ 時，$`P_n=1/4=-6.021`$ dB，$`D=1.5=1.761`$ dBi。由 7.782 dBi 減去 6.021 dB，得到相同答案。

> **核心觀念：** 正規化場型的 0 dB 是自己的最大值；指向性 dBi 的 0 dBi 是各向同性參考。兩者的參考不同。

## 5．波束立體角：把整個形狀壓成一個積分

影片對照：[約 34:00](https://www.youtube.com/watch?v=IBood8ipth4&t=2040s)－[45:00](https://www.youtube.com/watch?v=IBood8ipth4&t=2700s)；[54:00](https://www.youtube.com/watch?v=IBood8ipth4&t=3240s)－[64:00](https://www.youtube.com/watch?v=IBood8ipth4&t=3840s)

影片從總輻射強度推導指向性，再引入波束面積／波束立體角：

```math
\boxed{\Omega_A=\oint P_n\,d\Omega
=\int_0^{2\pi}\int_0^\pi
P_n(\theta,\phi)\sin\theta\,d\theta\,d\phi.}
```

因此

```math
\boxed{D_{\max}=\frac{4\pi}{\Omega_A}.}
```

$`\Omega_A`$ 的單位是 sr（立體弧度）；不是 m$`^2`$，也不是單一平面的弧度。

### 它不是只量「主瓣張開多少度」

想像將實際正規化功率搬進一個高度為 1 的等效區域，使總積分不變；該等效區域的立體角就是 $`\Omega_A`$。 實際旁瓣、背瓣的功率也會計入，並非只積分半功率輪廓內的面積。

### 三個立即可檢查的情境

| 情境                        | $`\Omega_A`$  | $`D_{\max}`$ |
|:----------------------------|:------------|:-----------|
| 各向同性 $`P_n=1`$            | $`4\pi`$ sr   | 1          |
| 電短偶極 $`P_n=\sin^2\theta`$ | $`8\pi/3`$ sr | 1.5        |
| 影片半球 $`\cos^2\theta`$     | $`2\pi/3`$ sr | 6          |

越多功率集中在較小角區，$`\Omega_A`$ 越小，$`D_{\max}`$ 越高。

### 相同主瓣，旁瓣增大會如何？

**補充解說／重算例題：**若保持峰值與主瓣形狀相同，只增加旁瓣，$`\oint P_n d\Omega`$ 增加，$`D_{\max}`$ 下降。 所以相同 HPBW 的兩個天線，可能有不同指向性；單一切面的主瓣寬度，並沒有涵蓋所有功率。

### 影片的寬主瓣示範

影片也比較平頂波束的模擬／量測資料。此類設計希望在指定角區維持接近相同的功率，不追求把所有能量擠到單一極窄峰值。比較時要依覆蓋範圍、旁瓣與波束效率，不宜只按峰值排序。

> **核心觀念：** 波束立體角是全空間「正規化功率的積分」；它將主瓣、旁瓣、背瓣都納入同一個集中程度指標。

## 6．由兩個主面寬度估指向性：只能當近似

影片對照：[約 64:00](https://www.youtube.com/watch?v=IBood8ipth4&t=3840s)－[69:00](https://www.youtube.com/watch?v=IBood8ipth4&t=4140s)

對集中在同一方向的窄主瓣，若旁瓣很低，可由兩個互相垂直主面的半功率寬度粗估波束立體角：

```math
\Omega_A\approx\theta_{\rm HP}\phi_{\rm HP}
\quad\text{（寬度用弧度）}.
```

再代入 $`D_{\max}=4\pi/\Omega_A`$。若用度數：

```math
\boxed{D_{\max}\approx
\frac{4\pi(180/\pi)^2}
{\theta_{\rm HP,deg}\phi_{\rm HP,deg}}
=\frac{41253}{\theta_{\rm HP,deg}\phi_{\rm HP,deg}}.}
```

41253 的單位換算不是 dB；計算得到的 $`D`$ 仍是線性比值。

### 影片的波束寬度乘積表

投影片列出不同理想場型或孔徑的經驗係數 $`K`$：

| 模型／用途             | $`D_{\max}\approx K/(\theta_{\rm HP,deg}\phi_{\rm HP,deg})`$ |
|:-----------------------|:-----------------------------------------------------------|
| 無旁瓣、矩形波束       | $`K=41253`$                                                  |
| 均勻矩形孔徑           | $`K=32383`$                                                  |
| 餘弦／均勻照明矩形孔徑 | $`K=35230`$                                                  |
| 均勻圓孔徑             | $`K=33709`$                                                  |
| 投影片給實際天線的粗估 | $`K\approx26000`$                                            |

係數差異反映波束形狀和其他方向功率。不能將其中一個數字當成所有天線的精確定律；知道完整場型時，應回到積分。

### 補充重算：10° 與 20°

使用 41253 得 $`D\approx206.3`$，約 23.14 dBi；使用 26000 得 $`D\approx130`$，約 21.14 dBi。僅換近似係數，就差約 2 dB，說明模型選擇會影響結果。

### 不適合直接套用的情境

大旁瓣、多主瓣、平頂波束、寬角度主瓣，或一個主面近乎全向時，兩寬度乘積可能不代表全空間積分。尤其不能只從某一窄切面，推論三維指向性很高。 **補充解說／重算例題：**影片以兩個約 150° 的切面搭配 10 dBi 提醒檢查數據。這可作合理性線索，但僅兩張切面不足以證明該三維場型不可能；仍須完整球面資料、角度定義與增益的校正基準。

> **核心觀念：** 兩個寬度能提供快估值；完整三維線性功率積分，才是指向性的定義。

## 7．波束效率：總輻射功率有多少落在主瓣？

影片對照：[約 69:00](https://www.youtube.com/watch?v=IBood8ipth4&t=4140s)－[71:20](https://www.youtube.com/watch?v=IBood8ipth4&t=4280s)

將波束立體角拆成主瓣區與其餘方向：

```math
\Omega_A=\Omega_M+\Omega_m,\qquad
\Omega_M=\int_{\rm main}P_n\,d\Omega.
```

影片定義波束效率：

```math
\boxed{\eta_B=\frac{\Omega_M}{\Omega_A}
=\frac{P_{\rm main}}{P_{\rm rad}},\qquad0\le\eta_B\le1.}
```

主瓣區域的邊界須說明，例如以第一零點包住的主瓣為範圍；不同範圍會得到不同效率。

### 補充重算：集中程度與功率比例一起看

若 $`\Omega_M=0.20`$ sr、其他瓣 $`\Omega_m=0.05`$ sr：

```math
\Omega_A=0.25\ {\rm sr},\qquad
D_{\max}=\frac{4\pi}{0.25}\approx50.27=17.01\ {\rm dBi},
```

```math
\eta_B=0.20/0.25=80\%.
```

若總輻射功率為 10 W，主瓣區域取得其中 8 W，其餘方向 2 W。

### 三種容易混用的「效率」

| 量             | 回答的問題                         |
|:---------------|:-----------------------------------|
| 匹配／失配因素 | 入射功率有多少進入天線端口？       |
| 輻射效率       | 接受功率有多少真正輻射到空間？     |
| 波束效率       | 已輻射的功率有多少落在指定主瓣區？ |

本單元的波束效率只談方向分配，不會辨別導體或介質發熱。一支耗損很高的天線，仍可能有高波束效率，但實際向目標送出的功率很小。

### 旁瓣抑制的用途與取捨

降低旁瓣可減少向其他方向送出的功率，也可降低接收非目標方向訊號的程度。但饋入權重改變時，主瓣寬度、峰值與旁瓣會一起變化；後續陣列單元將說明這些取捨。

> **核心觀念：** 高指向性表示峰值集中，高波束效率表示多數輻射功率在主瓣；兩者相關，但不是同一個定義。

## 8．五題自測與答案

所有指向性先算線性比值，再換成 dBi。

1.  $`P_n=\sin^2\theta`$，在 $`\phi`$ 方向全向。求 $`\Omega_A`$ 與峰值指向性。

2.  影片半球 $`\cos^2\theta`$ 場型，在 $`\theta=60^\circ`$ 的指向性是多少？若改成上下兩個半球均有 $`\cos^2\theta`$，峰值會如何？

3.  某正規化總功率場型積分 $`\Omega_A=0.5`$ sr。求 $`D_{\max}`$；若某方向為相對 $`-10`$ dB，該方向的 $`D`$ 是多少？

4.  E、H 面 HPBW 都為 10°。以 41253 估指向性是多少？這能當成精確答案嗎？

5.  $`\Omega_M=0.3`$ sr，$`\Omega_m=0.1`$ sr。求波束效率；能否由此判定輻射效率為 75%？

### 答案與檢查點

1.  $`\Omega_A=8\pi/3`$ sr；$`D_{\max}=1.5=1.761`$ dBi。

2.  $`D=6(1/4)=1.5=1.761`$ dBi。若上下半球都輻射，總積分加倍，峰值降為 3，約 4.771 dBi。

3.  $`D_{\max}=8\pi\approx25.133=14.002`$ dBi；該方向 $`P_n=0.1`$，故 $`D\approx2.513=4.002`$ dBi。

4.  $`D\approx412.53=26.15`$ dBi。這只是特定窄波束、低旁瓣模型的近似；真實答案要由完整場型積分。

5.  波束效率 $`0.3/(0.3+0.1)=75\%`$。不能判定輻射效率；後者還要知道端口接受功率和耗損。

### 公式速記

```math
D_{\max}=\frac{4\pi}{\Omega_A},\quad
D(\theta,\phi)=D_{\max}P_n(\theta,\phi),\quad
\eta_B=\frac{\Omega_M}{\Omega_A}.
```
