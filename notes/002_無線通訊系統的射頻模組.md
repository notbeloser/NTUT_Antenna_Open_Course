## 1．LO、混頻器、濾波器：頻率轉換三件組

影片對照：[約 02:00](https://www.youtube.com/watch?v=QbpX-J8aokE&t=120s)－[07:30](https://www.youtube.com/watch?v=QbpX-J8aokE&t=450s)

**LO 決定參考頻率；混頻器產生頻率組合；濾波器留下要用的頻率成分。** 單靠 LO 不會把資訊搬過去，單靠混頻也不會只剩下所需頻帶。

### 用三角恆等式看懂升頻

先用單一 IF 正弦波 $`A\cos(2\pi f_{\mathrm{IF}}t)`$ 來理解。乘上 LO 的 $`B\cos(2\pi f_{\mathrm{LO}}t)`$：

```math
v_{\mathrm{mix}}(t)=\frac{AB}{2}\left[
\cos 2\pi(f_{\mathrm{LO}}+f_{\mathrm{IF}})t+
\cos 2\pi(f_{\mathrm{LO}}-f_{\mathrm{IF}})t\right].
```

因此有和頻與差頻兩個主要成分：

```math
f_+=f_{\mathrm{LO}}+f_{\mathrm{IF}},\qquad
f_-=|f_{\mathrm{LO}}-f_{\mathrm{IF}}|.
```

帶通濾波器若留下 $`f_+`$，這就是本例要送進 PA 與天線的頻率。實際輸入若是一個承載資訊的頻帶，相乘會把整個頻帶搬移；不是把所有資訊變成單一無訊息的正弦波。 **補充解說／重算例題：**$`f_{\mathrm{IF}}=100`$ MHz，$`f_{\mathrm{LO}}=2.3`$ GHz：主要輸出在 2.4 GHz 與 2.2 GHz。若目標是 2.4 GHz，後級濾波器保留此頻帶，抑制 2.2 GHz 分量。

### 真實元件還有什麼？

影片提到元件的非線性會出現更多頻率成分，可概念性表示為 $`m f_{\mathrm{IF}}+n f_{\mathrm{LO}}`$。濾波器還要處理不需要的混頻產品與諧波。 濾波器的用途也不只選中心頻率。插入損耗、衰減速度與群延遲都會影響訊號；波形各頻率成分若受到不同延遲，可能使調變訊號失真。

### 降頻與鏡像的基本觀念

接收端把高頻訊號與 LO 混合，再選擇差頻交給 IF／基頻處理。 **補充解說／重算例題：**用 2.3 GHz LO 把 2.4 GHz 信號降至 100 MHz 時，2.2 GHz 信號也可能產生 100 MHz 差頻。這說明**前端頻帶選擇的重要性**：混頻後若已重疊，就不容易再分開。

> **核心觀念：** 變頻不是改寫資料內容，而是改變承載資料的頻譜位置。濾波器則決定哪些成分能繼續向後傳。

## 2．功率、天線與無線通道

影片對照：[約 00:00](https://www.youtube.com/watch?v=QbpX-J8aokE&t=0s)－[02:00](https://www.youtube.com/watch?v=QbpX-J8aokE&t=120s)、[07:30](https://www.youtube.com/watch?v=QbpX-J8aokE&t=450s)－[21:00](https://www.youtube.com/watch?v=QbpX-J8aokE&t=1260s)、[38:00](https://www.youtube.com/watch?v=QbpX-J8aokE&t=2280s)－[47:00](https://www.youtube.com/watch?v=QbpX-J8aokE&t=2820s)

| 放大器           | 位置與目的                         | 主要關注                 |
|:-----------------|:-----------------------------------|:-------------------------|
| IF 放大器        | 在變頻之前補足中頻訊號電平         | 增益、失真、頻寬         |
| 功率放大器 PA    | 在傳送端、天線之前提升射頻輸出功率 | 輸出功率、線性度、效率   |
| 低雜訊放大器 LNA | 在接收端前段放大小而弱的訊號       | 加入的雜訊、增益、線性度 |

**補充解說／重算例題：**PA 不會讓通道的物理損耗消失，而是提高傳送功率。LNA 也無法把已混入的雜訊「刪除」；它的目的是盡量少加雜訊，並降低後級雜訊對整體的影響。

### 天線同時有「進得去」與「送得出」兩種問題

-   **電路端：**前級送來的功率，有多少被天線接受？要看阻抗、匹配、反射與工作頻寬。

-   **空間端：**接受的功率，有多少真正輻射？往哪些方向輻射？要看效率、場型、指向性、增益與極化。

這是後續「電路參數」與「輻射參數」兩部分的主線。

### 多路徑：接收端收到的通常不只一束波

直接波、反射波、散射波、繞射波都可能抵達接收端。障礙物必須以**尺寸相對波長**理解，不能只用「大樓很大、桌子很小」的日常尺度判斷。 影片以 $`D`$ 與 $`\lambda`$ 的大小關係建立粗略直覺：大尺寸時用反射理解、接近波長時散射較複雜、很小尺寸時以繞射理解。 **補充解說／重算例題：**這個分類不是普遍適用的嚴格界線。繞射也會出現在大型障礙物的邊緣；材料、形狀與角度都會影響結果，三種機制可以同時存在。

### 衰落 Fading：相加有時增強、有時抵消

接收端要相加的是**帶相位的電場**，不是各路徑功率直接相加。兩路徑若相位接近，就可能增強；若相差約 180° 且振幅接近，就可能相消。 因此量到的起伏可能是真實的通道效應，不能看到曲線起伏就一律當成儀器隨機誤差。

> **核心觀念：** 「匹配很好」只說明端口接受功率的情況，不能保證輻射效率、空間覆蓋與多路徑下的接收表現都很好。

## 3．兩條路徑，就能造成訊號深谷

影片對照：[約 21:00](https://www.youtube.com/watch?v=QbpX-J8aokE&t=1260s)－[37:00](https://www.youtube.com/watch?v=QbpX-J8aokE&t=2220s)；相量複習與板書約 [23:00](https://www.youtube.com/watch?v=QbpX-J8aokE&t=1380s) 起

考慮平坦地面上的傳送、接收天線，高度分別為 $`h_t,h_r`$，水平距離為 $`d`$。只取直接波與地面反射波。

![單元 02 圖 02](images/002-diagram-02.png)

由幾何關系：

```math
r_1=\sqrt{d^2+(h_r-h_t)^2},\qquad
r_2=\sqrt{d^2+(h_r+h_t)^2}.
```

當 $`d\gg h_t,h_r`$，使用 $`\sqrt{1+x}\approx1+x/2`$：

```math
r_2-r_1\approx\frac{2h_th_r}{d}=\Delta r.
```

以 $`e^{j\omega t}`$ 為時間慣例，傳播路徑帶來 $`e^{-jkr}`$ 相位延遲，其中 $`k=2\pi/\lambda`$。兩路徑的場相量為

```math
\widetilde E=E_0\frac{e^{-jkr_1}}{r_1}
 +\Gamma E_0\frac{e^{-jkr_2}}{r_2}.
```

$`\Gamma`$ 是地面反射係數，可同時改變振幅與相位；本式將天線方向、極化等差異簡化到一致的 $`E_0`$。 令 $`\Gamma=\rho e^{j\psi}`$，且只對分母作 $`r_1\approx r_2\approx d`$ 近似，合成振幅為

```math
|\widetilde E|\approx\frac{E_0}{d}
\sqrt{1+\rho^2+2\rho\cos(\psi-k\Delta r)}.
```

所以 $`\rho=0.9`$ 時，理想起伏範圍可從直接波振幅的 0.1 倍到 1.9 倍，正是影片曲線要凸顯的現象。 影片以 $`\Gamma=-1`$ 說明相消，且令振幅分母 $`r_1\approx r_2\approx d`$，但**仍保留兩路徑的相位差**：

```math
|\widetilde E|\approx\frac{2E_0}{d}\left|\sin\frac{k\Delta r}{2}\right|
=\frac{2E_0}{d}\left|\sin\frac{2\pi h_th_r}{\lambda d}\right|.
```

當正弦項接近零，兩束波互相抵消；原本看似足夠的訊號，就可能跌到無法可靠解調的程度。

## 4．把公式用在工程判斷

影片對照：兩路徑推導約 [28:00](https://www.youtube.com/watch?v=QbpX-J8aokE&t=1680s)－[37:00](https://www.youtube.com/watch?v=QbpX-J8aokE&t=2220s)；以下數值與條件比較為補充例題

### 例題：路徑只多走一點，相位卻變很多

**補充解說／重算例題：**令 $`h_t=h_r=1.5`$ m，$`d=30`$ m，$`f=2.4`$ GHz。取 $`c=3\times10^8`$ m/s：

```math
\lambda=\frac{c}{f}=0.125\ \mathrm m,\qquad
\Delta r\approx\frac{2(1.5)(1.5)}{30}=0.15\ \mathrm m.
```

傳播相位差約為

```math
k\Delta r=\frac{2\pi(0.15)}{0.125}=2.4\pi\ \mathrm{rad}.
```

若再考慮 $`\Gamma=-1`$ 的反射相位，合成振幅為

```math
\frac{|\widetilde E|}{E_0/d}\approx2|\sin(1.2\pi)|\approx1.176.
```

直接波的單獨振幅 $`E_0/d`$ 並沒有變成合成振幅的兩倍。要看兩波的相位關系；換個位置或頻率，結果又可能差很多。

### 遠距離近似：場與功率的衰減不同

**補充解說／重算例題：**在 $`|2\pi h_th_r/(\lambda d)|\ll1`$ 時，$`\sin x\approx x`$：

```math
|\widetilde E|\approx\frac{4\pi E_0h_th_r}{\lambda d^2}.
```

此簡化兩路徑模型在這個條件下**場振幅約依 $`d^{-2}`$ 衰減，功率約依 $`d^{-4}`$ 衰減**。只有單一自由空間傳播路徑時，場振幅通常依 $`d^{-1}`$，功率密度依 $`d^{-2}`$。切勿把這兩種情境混用。

### 接收鏈需要注意什麼？

1.  天線攔截入射電磁場，建立可送進接收器的電訊號。

2.  帶通濾波器抑制頻帶外訊號；LNA 在弱訊號下盡量少加雜訊。

3.  混頻器與 LO 做降頻；IF／基頻再解調與解碼。

### 為什麼前幾級雜訊格外重要？

影片指出整體雜訊表現對前幾級尤其敏感，因此接收器前端採用 LNA。**補充解說／重算例題：**雜訊因子 $`F=\mathrm{SNR}_{\mathrm{in}}/\mathrm{SNR}_{\mathrm{out}}`$，雜訊指數 $`\mathrm{NF}=10\log_{10}F`$。兩級串接時，

```math
F_{\mathrm{total}}=F_1+\frac{F_2-1}{G_1}.
```

這裡 $`F_1,F_2,G_1`$ 都用線性值；第一級增益可降低第二級新增雜訊的相對影響。LNA 前的濾波器損耗也可能惡化整體 NF，所以不能只看 LNA 單顆的規格。

> **核心觀念：** 改善接收不能只靠「放大更多」：頻帶選擇、前端雜訊、反射相消、解調所需 SNR，都可能成為限制。

## 5．自測與答案

建議先用 5 分鐘作答，再核對解析。

1.  IF 為 70 MHz、LO 為 930 MHz，理想混頻器產生的兩個主要頻率是多少？若要發射 1 GHz，該保留哪一個？

2.  接收端已混入雜訊，為何 LNA 增益更大不代表 SNR 一定更好？

3.  兩束接收波各自的振幅為 $`A`$，相位相差 180°。相加後的場振幅是多少？可以直接將功率加成兩倍嗎？

4.  $`h_t=h_r=2`$ m、$`d=100`$ m，遠距離近似下的路徑差為何？若頻率 3 GHz，單看傳播的相位差是多少？

5.  使用兩路徑的遠距離 $`P_r\propto d^{-4}`$ 近似，距離加倍時功率變成幾分之一？約少幾 dB？

### 答案與解析

1.  和頻 1000 MHz，差頻 860 MHz。選擇 1000 MHz 所在頻帶，抑制 860 MHz 分量。

2.  前級雜訊與訊號會一起放大，LNA 自己也會加雜訊。要同時看雜訊表現與增益，並考慮後級；不能用輸出電平直接代表可靠度。

3.  在振幅相同且完全反相的理想條件下，場振幅為 0。功率由合成場的平方決定，不能忽略干涉項。

4.  $`\Delta r\approx2(2)(2)/100=0.08`$ m。$`\lambda=0.1`$ m，$`k\Delta r=1.6\pi`$ rad，即 288°。總相位關係還要包含反射係數。

5.  變為 $`1/16`$；$`10\log_{10}(1/16)\approx-12.04`$ dB。答案僅適用於題目指定的近似，不能套用到所有環境。

### 容易混淆的四件事

-   IF 放大器、PA、LNA 的功能與限制不同。

-   混頻後還需要濾波；頻帶已重疊後不容易分開。

-   多路徑不是只造成「多一點損耗」，也會有相位干涉。

-   場振幅與功率的距離次方關係相差一倍。
